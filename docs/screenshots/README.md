# 截图目录

此目录用于存放项目功能截图（README 中的「截图见 docs/」即指此处）。

欢迎贡献截图，命名建议：`功能名-说明.png`，例如：

- login.png        登录页
- pomodoro.png     番茄钟页面
- questions.png    题库列表
- quiz.png         刷题模式
- notes.png        笔记列表
- ocr.png          文字识别
- music.png        音乐播放器
- search.png       搜索结果

截图规范：建议 1280x800 左右，PNG 格式。
