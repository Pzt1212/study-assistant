学习助手 · 单机单人版  v1.1.0
================================

项目主页：https://github.com/Pzt1212/study-assistant
下载更新：https://github.com/Pzt1212/study-assistant/releases

一、这是什么
-----------
「学习助手」的本地单机版：把网页版整个打包成了一个免安装的 Windows
程序文件夹，无需安装 Python 或任何依赖，双击即可使用。

功能与网页版一致：仪表盘、番茄钟、计时器、背景音乐、题库刷题、笔记
（含手写板）、OCR 文字识别（内置离线引擎，支持简体中文印刷体）、
论坛、视频库等，全部数据保存在本机，不联网也能用。

二、怎么用
-----------
1. 解压后，双击文件夹里的「学习助手.exe」；
2. 程序会自动启动服务，并自动打开浏览器访问
   http://127.0.0.1:5000（若浏览器没自动弹出，手动打开该地址即可，
   端口被占用时以控制台窗口显示的「访问地址」为准）；
3. 单人模式下已自动登录，无需输入账号密码，打开即是你的工作台；
4. 关闭黑色控制台窗口（或按 Ctrl+C）即退出程序。

三、账号说明
-----------
首次启动会自动创建一个管理员账号并写入 data/账号信息.txt
（用户名默认 user，密码为随机 6 位数字）。由于单人模式自动登录，
通常无需手动输入；仅当需要在浏览器里手动登录时才用得上。

如需自定义账号，可在启动前设置环境变量：
    STANDALONE_USERNAME=你的用户名
    STANDALONE_PASSWORD=你的密码

四、数据保存在哪
-----------
全部数据都在本文件夹内（绿色便携，删除文件夹即完全卸载）：
    data\     数据库（账号、笔记、题目等所有数据）
    uploads\  上传的文件
    logs\     运行日志
    video\    本地视频库（如需使用视频功能，把视频放到这个目录）

备份 = 复制整个文件夹；换电脑 = 把整个文件夹拷过去再双击 exe。
重置账号/数据 = 退出程序后删除 data 文件夹，下次启动会重新初始化。

五、常见问题
-----------
1. 双击后闪退 / 打不开？
   先看 logs\server.log 里的报错；最常见原因是 5000 端口被占用，
   程序会自动改用 5001+ 端口，看控制台窗口里显示的「访问地址」。
2. 已在运行时再次双击？
   程序检测到已运行，会直接打开浏览器而不会启动第二个。
3. 杀毒软件报警？
   PyInstaller 打包的 exe 偶尔会被误报，选择「信任/允许」即可；
   本程序完全离线本地运行，不外发任何数据。
   （可通过 Release 页面提供的 SHA-256 校验下载文件是否完整。）
4. OCR 手写识别？
   单机版内置印刷体 OCR（中/英）；手写体识别需额外插件，
   参考 Web 版源码 requirements-handwriting.txt。

六、与网页版的区别
-----------
- 单人使用：自动登录，注册入口已禁用（保持单用户）；
- 媒体库（R2 云直传）、在线题库、在线轻音乐等需要外部服务或云配置
  的功能默认不可用，其余功能不受影响；
- Web 版源码与开发文档见 GitHub 仓库 Pzt1212/study-assistant。
