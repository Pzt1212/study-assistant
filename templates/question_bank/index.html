接入你的题库 API {% if not enabled %}已关闭{% endif %}

本项目不内置任何题目，也不提供公共接口。你需要自备一个「一题一答」的 JSON 接口：请求时带上题目参数 q，响应中返回 answer 字段即可。

接口约定与示例 
GET {你的地址}?q=题目内容&token={令牌}

// 支持的响应结构（任选其一）
{"answer": "答案文本"}
{"data": {"answer": "答案文本"}}
{"data": "答案文本"}

接口地址与令牌也可通过环境变量预置： QUESTION_BANK_API_URL、QUESTION_BANK_TOKEN， 页面上留空时会自动取用。
